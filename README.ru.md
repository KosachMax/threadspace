# Threadspace

Боковая навигация по тредам BB в стиле Notion: нейтральная светлая и тёмная палитры, эмодзи проектов, избранное, дерево вложенных тредов и архив при наведении.

Русский и английский выбираются автоматически по языку интерфейса BB (`document.documentElement.lang`), с обновлением без перезагрузки. Если BB не указал язык, используется язык браузера; для других языков — английский. Названия проектов и тредов остаются пользовательскими данными.

Нажмите на эмодзи проекта, чтобы открыть выбор эмодзи и цвета. Можно найти эмодзи, выбрать категорию или вставить свой. Изменения сохраняются в хранилище плагина и синхронизируются между окнами.

Русские названия и ключевые слова эмодзи взяты из [Unicode CLDR](https://cldr.unicode.org/translation/characters/short-names-and-keywords). Данные входят в сборку и работают без сети; источник и лицензия находятся в `licenses/UNICODE-CLDR.txt`, скрипт обновления — `scripts/update-emoji-ru.mjs`.

Слева от треда показан значок его провайдера из подключённых в BB. При наведении видно название провайдера. Справа используются штатные статусы BB; отдельная точка непрочитанного результата не дублируется.

Во время работы агента показан небольшой спиннер с восемью тонкими штрихами. Все спиннеры используют общую фазу анимации, в том числе появившиеся позже. При включённом уменьшении движения спиннер остаётся статичным.

Состояния обновляются из живого списка BB. Вопрос или подтверждение обозначается облачком с вопросом, ошибка выполнения или отправки — треугольником с восклицательным знаком. Ожидание запуска, подготовка окружения и недоступная машина показаны часами с разными подсказками. Непрочитанный результат обозначается одной точкой. Штатные значки сценариев, целей, планирования и сторонних плагинов сохраняются. Только свёрнутый проект показывает компактную сводку «число + спиннер / число + вопрос» без видимого текста. Нулевые части и разделитель без пары скрываются. Если внутри нет работы и вопросов, рядом с названием нет ни сводки, ни общего числа тредов.

При наведении или фокусе клавиатуры справа от треда появляются кнопки архива и меню действий. Архивация использует штатное действие BB, включая подтверждение, обработку дочерних тредов, закрытие панелей и отмену. Внизу списка есть архив с восстановлением тредов.

В меню каждого треда есть «Сгенерировать название заново». Название строится по сообщениям выбранного треда, без перехода в него или запуска агента. Используется сервис из BB → AI services → Thread titles: сейчас поддерживается bb cloud, выбранный явно или первым доступным в Automatic. Модель определяет сам сервис. У установленного BB нет общего публичного вызова генерации для других сервисов, включая Codex; такой выбор показывает ошибку и сохраняет прежнее название. Off, недоступность сервиса и ошибки также сохраняют название. Параллельное ручное переименование обнаруживается перед сохранением.

При задержке курсора на любом треде открывается предпросмотр «Контекст»: полное название, проект, окружение или worktree, ветка, состояние Git, текущий статус, фрагмент последнего сообщения, провайдер, модель и время обновления. Путь и машина раскрываются внутри карточки. Карточка работает также для вложенных, избранных и архивных тредов. Наведение не открывает тред и не помечает результат прочитанным; Escape закрывает карточку.

На телефоне и при сенсорном управлении строки и зоны нажатия крупнее, названия занимают до двух строк, а отступы глубокого дерева ограничены. Справа постоянно доступна одна кнопка меню: статус треда занимает место троеточия, пока тред работает или требует внимания. Архив находится в штатном меню. Пункт «Информация о треде» открывает «Контекст» в нижней карточке без перехода в тред; долгое нажатие также открывает штатное меню. Выбор эмодзи и цвета использует такую же карточку с прокруткой. Режим сохраняется при повороте телефона; поля ввода и высота карточки учитывают экранную клавиатуру. Название проекта раскрывает и сворачивает список. Обычное касание открывает тред и закрывает мобильную панель BB, а начало прокрутки не меняет выделение.

Подробности загружаются только после наведения, с коротким кешем, отменой устаревших запросов и ограничением времени ожидания. Отсутствие данных Git отличается от отсутствия репозитория. Счётчики коммитов показывают сравнение с подписанной базовой веткой, а не с удалённой tracking-веткой.

Панель и выбор эмодзи автоматически следуют светлой или тёмной теме приложения BB. Отдельной настройки темы и дополнительного поиска тредов нет: для поиска используется штатный поиск BB. Свёрнутые группы сохраняются для каждого клиента отдельно.

## Значки статусов

У треда справа показывается не больше одного значка. Если подходят несколько состояний, побеждает то, что выше в таблице.

| Значок | Статус | Что значит | Что делать |
|:---:|---|---|---|
| <img src="docs/status/waiting.svg" width="20" height="20" alt="waiting"> | Ждёт тебя | Агент задал вопрос или просит подтверждение. Тред также виден в секции **Ждёт тебя** сверху. | Открыть тред и ответить. |
| <img src="docs/status/error.svg" width="20" height="20" alt="error"> | Ошибка | Запуск упал или сообщение из очереди не отправилось. | Открыть тред и посмотреть причину. |
| <img src="docs/status/queued.svg" width="20" height="20" alt="queued"> | В очереди | Сообщение ждёт запуска, готовится окружение или машина недоступна. Причина — в подсказке при наведении. | Подождать или проверить машину. |
| <img src="docs/status/working.svg" width="20" height="20" alt="working"> | Работает | Агент работает, запускается или останавливается. Все спиннеры крутятся синхронно. | Ничего, закончит сам. |
| <img src="docs/status/unread.svg" width="20" height="20" alt="unread"> | Не прочитано | Агент закончил, а результат ты ещё не открывал. Название жирное. | Открыть тред. |
| <img src="docs/status/draft.svg" width="20" height="20" alt="draft"> | Черновик | В поле ввода есть неотправленное сообщение. | Отправить или стереть. |
| <img src="docs/status/pinned.svg" width="20" height="20" alt="pinned"> | Закреплён | Тред закреплён наверху своего проекта. Виден, только если нет другого статуса. | Открепить кнопкой при наведении. |

**Свёрнутый проект или родительский тред** показывает счётчик вместо одного значка, например `2` <img src="docs/status/working.svg" width="20" height="20" alt="working"> `/` `1` <img src="docs/status/waiting.svg" width="20" height="20" alt="waiting">: внутри два треда работают и один ждёт тебя. Если внутри ничего не работает и не ждёт, рядом с названием пусто.

Значки других плагинов в строке треда сохраняются как есть.

## Подключение

После `npm install --include=dev` и `npm run build` установите плагин: `bb plugin install .`.

Выбор списка: `bb settings ui set sidebar.threadListProvider threadspace/notion-sidebar`.
Возврат к стандартному: `bb settings ui set sidebar.threadListProvider thread-list/thread-list`.

Плагин заменяет область списка тредов. Нативная шапка BB, кнопка нового треда, навигационный rail и нижние элементы остаются под управлением BB. Меню треда, навигация, статусы, черновики, горячие клавиши и перенос в split используют публичный SDK.

## Проверка и визуальное демо

Скрипты проверок находятся в `package.json`. Backend проверяется официальным SDK harness с настоящим SQLite, frontend — SDK app harness. Проверяются сохранение и конкурентные изменения эмодзи, перезагрузка плагина, вызов штатного архива, навигация, скрытые треды и тема.

Визуальная демонстрация использует тот же компонент панели: `npm run preview:build`, затем `npm run prototype`, открыть <http://localhost:4317>. В демонстрации показаны примеры тредов; они не связаны с реальными данными BB.

Визуальный ориентир — [боковая панель Notion](https://www.notion.com/help/navigate-with-the-sidebar). Threadspace — самостоятельный плагин BB; функции Notion, не связанные с навигацией по тредам, не реализованы.
